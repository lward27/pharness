# Archive

The archive preserves superseded or historical material without presenting it
as current direction. Nothing here should be used as implementation or
deployment authority without revalidation and an explicit move back into an
active lifecycle directory.

## Contents

- [`foundations/`](foundations/) contains the original harness-planning prompt
  and comprehensive implementation plan. They were superseded by shipped
  V2/V3 milestones and are not the runtime system prompt.
- [`roadmaps/`](roadmaps/) contains the earlier autonomous-SDLC roadmap whose
  stated next cut lines have already shipped or changed.
- [`reviews/`](reviews/) contains historical current-build reviews.
- [`ui/`](ui/) contains superseded minimal and V2 UI direction.
- [`v2/`](v2/) contains V2 plans, handoffs, and cluster smoke material.
- [`runbooks/`](runbooks/) contains manual API/CLI smokes superseded by the
  environment-ready WorkItem flow and operator cockpit.
- [`notes/`](notes/) contains retained scratch or pasted planning material.

Git history preserves each file's original path and chronology. Archival is a
lifecycle classification, not deletion.
